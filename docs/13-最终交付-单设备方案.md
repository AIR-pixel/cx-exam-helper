## 五、关键坑与解法（都踩过并解决）

1. **IME 隐身是误判**：实测 IME 层是普通层，会被抓拍。已推翻，不用。
2. **SKIP API 找不到**：不是被删，是 hidden API 过滤。LSPosed 模块内调用可绕过（框架豁免模块）。
3. **TYPE_APPLICATION_OVERLAY 画不出**：HyperOS 上服务添加的悬浮窗窗口存在但 buffer 空（卡 READY_TO_SHOW）。**改用普通 Activity 显示**，已验证。
4. **bootloop 卡 fastboot**：反复重启扣光 ABL retry（A 槽 unbootable）。用 `fastboot --set-active=a` + reboot 救回（工作区 `2026-10-23-11-24-14/fastboot-rescue.bat`）。根因非 GNSS 元凶复发（db 里已无 com.air.locspoof→system 行）。
5. **lspd 配置库写坏**：早期 `cat >` 覆盖主 db 导致 WAL 依赖错乱。后用 python sqlite3 构造自包含 db（`journal_mode=DELETE`）写回。当前 db 健康。
6. **前台服务通知 Bad notification**：加 `setSmallIcon(android.R.drawable.ic_dialog_info)` + POST_NOTIFICATIONS 权限。
7. **shell 启动后台服务被拦**：改 Main.onCreate 自动 startForegroundService，`am start` 打开即起。
8. **focus 变 null**：无焦点叠层 Activity 启动后 mCurrentFocus=null，但学习通仍顶层、未被 cover。是否触发学习通切屏上报**需进真实考试验证**——这是最后一个未实测风险。
